📚 Ringkasan Materi

Pada materi HTML, kita mempelajari berbagai tag untuk membuat struktur sebuah halaman web.

Salah satu materi yang dipelajari adalah penggunaan elemen <img> untuk menampilkan gambar pada halaman website.

HTML digunakan untuk membuat struktur halaman, sedangkan CSS digunakan untuk mengatur tampilan agar halaman menjadi lebih menarik dan rapi.
